Network Intrusion Detection and Response System

NIDRS

A machine-learning security project that spots attacks on a network, explains them, and tells the analyst what to do next.

About the project

Networks carry far more traffic than a person can check by hand, and most intrusion detection tools stop at raising an alert. NIDRS goes one step further: it detects suspicious traffic with two machine-learning models, enriches every alert with context, and recommends a response, all inside one security dashboard.

🛡 Detects

Classifies known attack types and flags unusual live traffic.

🔎 Explains

Adds attack technique, location and reputation of the source address.

⚔ Responds

Assigns a risk level and lists recommended actions.

📣 Reports

Live dashboard, email for critical alerts and incident reports.

How it works

1

Capture traffic

Scapy listens to live network packets and groups them into flows (one conversation between two endpoints).

2

Extract features

Six measures per flow: packet count, total bytes, duration, packets per second, bytes per second and average packet size.

3

Detect

A Random Forest classifies known attack categories. An Isolation Forest flags live flows that look unusual.

4

Enrich

Every stored alert gets its attack technique from the MITRE framework, the country of the source address and an abuse-reputation score.

5

Respond

A rule-based engine assigns a risk level and lists recommended actions for the analyst.

6

Alert and report

Alerts are stored in an SQLite database and shown on the dashboard. Critical alerts are emailed with an incident report attached.

The two detection models

Random Forest (supervised)

  • Trained on the Network Security Laboratory–Knowledge Discovery in Databases dataset: 125,973 records, 41 features.
  • Five classes: Normal, Denial of Service, Probe, Remote to Local, User to Root.
  • The Synthetic Minority Over-sampling Technique balances rare classes in the training data only.
  • The difficulty column is dropped to prevent data leakage.

Isolation Forest (unsupervised)

  • Works on live traffic, where no attack labels exist.
  • Scores the six flow features and flags the most unusual flows (about 5% by design).
  • Trained on flows captured from a real network.
  • Flagged flows become “Live Anomaly” alerts.

Accuracy (XP bar)

Five-class model: about 99.9%. Binary attack-versus-normal model: about 99.9%.

Measured on a 20% stratified hold-out split. The rarest class, User to Root, is the hardest to detect.

Honest limits: accuracy comes from a random split of the training dataset, so the official test file would score lower. The live Isolation Forest has no labels to measure accuracy against. Location and reputation lookups need internet access, and the reputation score also needs a free API key.
